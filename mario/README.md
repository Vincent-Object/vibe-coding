# SUPER MARIO · JS Edition

纯 HTML5 Canvas + 原生 JavaScript 实现的 NES 风格超级马里奥，**零依赖、零构建**。
所有像素画、芯片音乐、关卡都由代码生成，没有任何外部资源。

## 启动

任选其一：

- 双击 `index.html`（任意现代浏览器）
- 双击 `启动游戏.bat`

## 操作

| 按键 | 功能 |
| --- | --- |
| ← → | 移动 |
| ↑ | 跳跃（按住跳得更高，助跑跳得更远） |
| ↓ | 蹲下（变大后） |
| X / Shift | 加速跑；火力马里奥时发射火球 |
| Enter | 开始 / 暂停 |
| M | 静音 |

## 内容

- **10 个关卡**：1-1 ~ 3-2，包含地上、地下、夜间空中平台、城堡四种主题
- 城堡关（1-4 / 2-4 / 3-2）末尾有 **库巴决战**：跳过他碰斧子斩断吊桥，或用火球击败他
- 蘑菇变大、火之花、踩敌人、龟壳连击、食人花、砖块金币、旗杆结算、时间分数
- 经典规则：100 金币 = 1UP，掉坑/碰岩浆/时间归零即死，Game Over 后可按 Enter 续关
- 标题画面用 ← → 可选择已解锁的关卡（进度存在 localStorage）

## 文件结构

```
index.html        入口
js/sprites.js     NES 调色板 + 像素画精灵 + 图块 + 位图字体
js/levels.js      10 个关卡（构建器 DSL 生成）
js/audio.js       WebAudio 芯片音源（方波/三角波，原创旋律）
js/game.js        引擎：物理、碰撞、敌人 AI、状态机、渲染
```
